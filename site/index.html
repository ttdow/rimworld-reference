A note on the numbers

Values come directly from the supplied spreadsheets. Apparel armor values are shown as supplied; material and quality adjustments have not been calculated. Textile multipliers are marked ×.

Insulation multipliers and fixed °C values stay separate. A dash (—) means a blank source cell, never zero. Use All columns or select an item to see every field.

Egg output is per female, using the CSV’s maximum-production estimates. Annual output uses a 60-day year. Percentages are shown as supplied, including ratios above 100%; they are not recalculated from rounded inputs.

Female feed and total breeder feed are separate measures. Male ratios are approximate males per female for continuous fertilization. Male for egg output refers to laying eggs, not hatching chicks. Select an animal for all fields and wiki links.

Milk output and feed figures are the CSV’s supplied estimates per adult female. Annual output uses a 60-day year. Feed efficiency and hay needs are preserved as supplied, not recalculated from rounded inputs.

Percentages are shown as supplied. A dash (—) means a blank source cell, never zero. Comfortable temperatures use °C; pack capacity uses kg. Select an animal for notes, all fields, and wiki links.
